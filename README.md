# Kamlesh Pawar - Software Developer Portfolio

A clean, professional portfolio website showcasing my skills, projects, and experience as a Full-Stack Developer with AI integration.

## 🚀 Features

- **Modern Design**: Clean, responsive UI with smooth animations
- **AI Chat Assistant**: Yutsumi - powered by Groq API
- **Project Showcase**: Interactive project cards with impact statements
- **Mobile Responsive**: Optimized for all devices
- **Performance**: Fast loading with optimized assets

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **AI**: Groq API integration
- **Styling**: Modern CSS with animations
- **Deployment**: Vercel static hosting

## 📁 Project Structure

```
kamlesh-portfolio/
├── public/           # Static assets
│   ├── index.html    # Main portfolio page
│   ├── bg.png        # Background image
│   └── ...           # Other assets
├── server.js         # Express backend for AI chat
├── .env            # Environment variables
└── vercel.json       # Deployment configuration
```

About

I started with curiosity about how software actually works behind the screen.

At first, I was focused mostly on backend logic — understanding how systems communicate, how data flows, and how everything connects. Over time, I realized that the frontend is where users truly experience the system. That's where clarity matters most.

Now, I focus on building interfaces that don't just look good, but feel right to use. Fast loading. Clear structure. No unnecessary complexity.

I primarily work with React, Next.js, and modern frontend tools, while also building backend components using Python and FastAPI when needed.

I'm currently interning at Nelumbus Technologies, contributing to an AI-based assessment platform — building backend features, real-time systems, and optimizing agent workflows.

I'm also actively exploring GenAI concepts like prompt engineering, RAG pipelines, and agent-based workflows.
